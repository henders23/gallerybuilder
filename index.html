Export your gallery

You get one HTML file. Open it in any modern browser to walk through the gallery — put it on any web host to share it.

  • The 3D engine (three.js) loads from the internet, so viewers need to be online.
  • Your design travels inside the file: open it here again with File → Open to keep editing.

How it works

Everything snaps to a half-metre grid. Select anything to change it in the panel on the right. Your work saves itself in this browser as you go.
